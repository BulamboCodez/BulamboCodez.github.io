# CB Portfolio

Chimwemwe Bulambo's personal portfolio website for Chimwemwe Bulambo showcasing skills, projects, and contact details. The site is built with plain HTML, CSS, and JavaScript for a fast, responsive experience.
This is done to build skills in AI prompting as well and to review and learn more on web developing 
## Features

- Clean, modern portfolio layout
- Responsive design for desktop and mobile
- Sections for About, Projects, Skills, and Contact
- Lightweight implementation with no external dependencies

## File Structure

- `index.html` – main portfolio page
- `styles.css` – layout and styling rules
- `logic.js` – interactive behavior and page scripting
- `robots.txt` – search engine crawling instructions
- `Assets/icons` – browser tab icon location
- `Assets/images` – profile images and image assets
- `Assets/pdfs` – PDF documents (for future use)

## Getting Started

### Prerequisites

- Any modern web browser

### Run locally

1. Open the project folder.
2. Open `index.html` in your browser.

## Usage

- Navigate using the menu links to explore the portfolio sections.
- Use the contact section to send an email to `chimwemwebulambo000@gmail.com`.

## Customization

- Update `index.html` to change text, links, and section content.
- Modify `styles.css` to adjust colors, spacing, and typography.
- Add new behavior or animations in `logic.js`.

## Notes

This portfolio is designed to be simple, accessible, and easy to deploy as a static website.
